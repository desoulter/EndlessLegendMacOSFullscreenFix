# Endless Legend macOS Fullscreen Fix 1.1.0

Исправление переключения приложений в полноэкранном режиме нативной macOS-версии
Endless Legend. Сохраняет Retina, выбор разрешения и большой интерфейс, устраняет
чёрный экран при смене контекста OpenGL и при неподдерживаемом количестве сэмплов MSAA.

Установщик собирает нативную библиотеку из исходников и применяет патч к локальной
установке игры. Готовые библиотеки и игровые файлы в репозиторий не входят.

## Совместимость

Исправление рассчитано на конкретный Intel-билд игры для macOS. На Apple Silicon
игра и библиотека работают через Rosetta. Установщик проверяет точную контрольную
сумму исполняемого файла и структуру PlayerSettings; неизвестные сборки отклоняются.
Подробности совместимости и SHA-256 приведены в [английском README](README.md).
Сборка Windows под CrossOver этим патчем не поддерживается.

### Проверенная конфигурация

| Компонент | Версия / конфигурация |
| --- | --- |
| Процессор | Apple M4 Pro |
| macOS | 26.6.2 |
| Unity | 5.3.6p1 |
| ELCP | 2.7.9 S3 |
| Разрешения | 3024×1890, 2048×1330, 1920×1200 |
| Параметры экрана | Нативный полноэкранный режим, Retina, большой интерфейс |
| Переключение приложений | Cmd-Tab |
| Steam Overlay | Выключен |

Патч совместим с отдельными исправлениями звука роликов и графических артефактов.
Область проверки и дополнительные тесты описаны в [TESTING.md](docs/TESTING.md).
Перед установкой удалите другие полноэкранные патчи их собственными установщиками.

## Установка

Нужны Python **3.9+** и Apple Command Line Tools либо Xcode. Пакеты pip и Mono не нужны.

1. Закройте игру и откройте Terminal в каталоге клонированного репозитория.
2. Проверьте наличие инструментов:

   ```sh
   python3 --version
   xcrun --find clang
   ```

   Если инструменты Apple не установлены:

   ```sh
   xcode-select --install
   ```

   Завершите установку в появившемся системном окне.

3. Проверьте совместимость и установите исправление:

   ```sh
   python3 fullscreen_fix.py install --dry-run
   python3 fullscreen_fix.py install
   python3 fullscreen_fix.py status
   ```

`--dry-run` проверяет совместимость игровых файлов и резервных копий без изменения
игры. Команда `install` компилирует `src/ELContextFixNative.m`, сохраняет оригиналы
и применяет патч. Для отдельной проверки компилятора и сборки используйте `build`.

По умолчанию игра ищется в:

```text
~/Library/Application Support/Steam/steamapps/common/Endless Legend
```

Для другой библиотеки Steam добавьте путь к каталогу, **содержащему** `EndlessLegend.app`:

```sh
python3 fullscreen_fix.py install --game-dir "/Volumes/Games/Steam/steamapps/common/Endless Legend"
```

Тот же аргумент используется с `status` и `uninstall`.

Запускайте игру через Steam. В разделе «Видео» включите полноэкранный режим и
выберите разрешение. В разделе «Интерфейс» при необходимости включите большой
интерфейс. Сглаживание MSAA ограничивается максимумом драйвера
`GL_MAX_SAMPLES_EXT` — 4× в проверенной конфигурации. Остальные параметры качества
сохраняются.

## Ограничение кадров и обновление библиотеки

Для обновления целой установки 1.0.0 или 1.1.0 закройте игру и из каталога
исходников новой версии выполните:

```sh
python3 fullscreen_fix.py update --fps-cap 60
```

Команда собирает и заменяет только нативную библиотеку и manifest установки,
сохраняет лимит в `ContextFix/runtime-options.json`. После этого запускайте игру
через Steam как обычно — логгер и диагностический наблюдатель не нужны.
Разрешение, Retina, MSAA и остальные настройки качества сохраняются.
Лимит задаёт верхнюю границу; фактическая частота может быть ниже.

Для первой установки используйте `install --fps-cap 60`. Без отдельной настройки
дополнительный лимит выключен. После обновления библиотеки изменить лимит либо
выключить его можно так:

```sh
python3 fullscreen_fix.py configure --fps-cap 100
python3 fullscreen_fix.py configure --fps-cap 0
```

Настройка применяется при следующем запуске игры. При удалении патча файл
предпочтений сохраняется, но без библиотеки не действует. `update` проверяет
целостность установленного поддерживаемого патча и резервных копий; неизвестные
экспериментальные версии этой командой не мигрируются. Вызов `update` без
`--fps-cap` сохраняет текущий лимит; в установке 1.0.0 без файла предпочтений
дополнительное ограничение останется выключенным.

В двух отмеченных трёхминутных прогонах туториала при 2048×1330, MSAA 4× и
заданном лимите 60 фактически получилось около 54/53 present в секунду,
3,48/3,43 Вт GPU для original/patched. Камера была выставлена примерно одинаково.
Подробности и ограничения сравнения — в [журнале исследования](docs/POWER-INVESTIGATION.ru.md).

## Проверка и удаление

Закройте игру перед удалением:

```sh
python3 fullscreen_fix.py status
python3 fullscreen_fix.py uninstall
```

Оригиналы и сведения об установке хранятся в каталоге **`ContextFix/` внутри папки
игры**. Сохраняйте этот каталог до удаления исправления. Удаление восстанавливает
исходные байты и права доступа исполняемого файла, настроек и Info.plist, затем
убирает библиотеку и сведения об установке. Резервные копии остаются.

Если игровые файлы или резервные копии были изменены после установки, операция
останавливается до перезаписи. Проверка файлов Steam и обновления игры могут
заменить пропатченные файлы — состояние можно проверить командой `status`.

## Ошибка запуска: `missing LC_UUID load command`

Ранняя сборка с флагом `-Wl,-no_uuid` создавала библиотеку без UUID. macOS/Rosetta
отклоняет такую библиотеку до запуска Unity. В исправленном установщике UUID
сохраняется и проверяется перед установкой.

Закройте игру и выполните из каталога репозитория с исправленной сборкой:

```sh
python3 fullscreen_fix.py uninstall
python3 fullscreen_fix.py install
python3 fullscreen_fix.py status
```

Для другой библиотеки Steam добавьте тот же `--game-dir` ко всем командам.
Удаление работает и для установки с ошибочной библиотекой.

## Как это работает

1. Установщик добавляет в свободное место заголовка Mach-O команду загрузки нативной
   библиотеки. Инструкции самого движка не переписываются.
2. До инициализации Unity библиотека перехватывает замену OpenGL-контекста у
   `PlayerWindowView` и отсоединяет старую поверхность вызовом `clearDrawable`.
   Это предотвращает сбой при переходе в полноэкранный режим.
3. Два поля PlayerSettings включают нативный полноэкранный режим macOS, допускающий
   переключение приложений, и изменение размеров окна.
4. Поддержка Retina включается в Info.plist и у OpenGL-поверхности. Точечные
   перехваты согласуют физические пиксели, логические точки и выбранное разрешение.
5. Перед выделением полноэкранных буферов цветности и глубины запрос MSAA
   ограничивается значением `GL_MAX_SAMPLES_EXT`. Запрос 8 сэмплов при максимуме
   драйвера 4 приводит к ошибке выделения буферов и чёрному экрану.

Патч использует штатный вывод кадра Unity. Управляемые DLL, сохранения, звук
роликов, шейдеры и многопоточный рендеринг не меняются. Исправления звука и
графических артефактов могут использоваться одновременно.

Подробный разбор с адресами перехватов: [HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md).

## Отдельная сборка и тесты

Для сравнения нагрузки GPU, температуры и вентиляторов с патчем и без него есть
отдельный [логгер и инструкция](docs/BENCHMARK.ru.md). Он сохраняет CSV/JSON и
создаёт HTML-сравнение двух ручных прогонов.

```sh
python3 fullscreen_fix.py build
python3 -m unittest discover -s tests -v
```

Сборка создаёт `.build/libELContextFixNative.dylib` и `.build/build.json` с
контрольными суммами. Эти файлы не входят в Git. Обычные тесты используют
синтетические данные и не требуют игры или компилятора. Проверки на настоящих
игровых файлах выполняются отдельно на временных копиях — см. [TESTING.md](docs/TESTING.md).
